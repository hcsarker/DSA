
# Contributing to DSA

Thanks for your interest in contributing! This repository is intended as a learning and practice space. Please follow these simple guidelines to keep the project helpful and consistent.

## How to contribute

- Fork the repository and create a feature branch for your changes.
- Keep changes focused: one problem or note per commit/PR.
- Use descriptive filenames (example: `two_sum.cpp`, `binary_tree_traversal.cpp`).
- Add or update a short comment at the top of C++ files describing the problem and complexity.

## Coding style

- Use clear variable names and small helper functions.
- Aim for readability rather than golfing lines.
- Keep each file self-contained (include necessary headers and a minimal `main()` if helpful).

## Pull requests

- Open a PR against the `HCS` branch with a concise description of changes.
- Link to the problem or include a short problem statement when relevant.
- I will review and merge; expect small formatting or naming suggestions.

## Notes

- This repository is primarily an educational practice repo; contributions are welcomed but not required to follow strict library-level rules.

Thanks — and happy coding! 🚀
