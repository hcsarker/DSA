# Solved DSA Codes

## DSA ✨ — Data Structures & Algorithms

> A curated collection of algorithm and data structure implementations, notes, and small practice programs. Clean, minimal, and ready for experimentation.

[View on this machine](./)

***

**Why this repo:**

* **Learn:** Clear examples for classic algorithms and problems.
* **Practice:** Small, self-contained programs you can compile and run.
* **Reference:** Quick notes for common patterns and interview-style problems.

**Highlights:**

* Visual and easy-to-follow C++ examples
* Structured by topic (Array, String, Tree, Linked Lists, Stack)
* Compact notes for LeetCode & SQL practice

***

**Quick Start**

* Build a single C++ file (from VS Code build task or terminal):

```bash
g++ -fdiagnostics-color=always -g src/file.cpp -o bin/file
./bin/file
```

* Recommended: open a folder (e.g., `Array/`, `Tree/`) and run the provided examples.
