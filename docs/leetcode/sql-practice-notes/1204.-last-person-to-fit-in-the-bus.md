# 1204. Last Person to Fit in the Bus

## Table: Queue

| Column       | Type    |
| ------------ | ------- |
| person\_id   | int     |
| person\_name | varchar |
| weight       | int     |
| turn         | int     |

👉 `turn` → boarding order

***

## 🎯 Problem

Find:

```
last person whose total weight ≤ 1000
```

***

## 🧠 Key Idea

👉 cumulative sum (running total) করতে হবে

```
turn অনুযায়ী weight যোগ করতে হবে
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT person_name
FROM (
    SELECT 
        person_name,
        SUM(weight) OVER (ORDER BY turn) AS total_weight
    FROM Queue
) q
WHERE total_weight <= 1000
ORDER BY total_weight DESC
LIMIT 1;
```

***

## 🔎 Explanation

### Step 1 — Running sum

```
SUM(weight) OVER (ORDER BY turn)
```

👉 1st → w1\
👉 2nd → w1 + w2\
👉 3rd → w1 + w2 + w3

***

### Step 2 — Filter valid

```
total_weight <= 1000
```

***

### Step 3 — Last person

```
ORDER BY total_weight DESC
LIMIT 1
```

👉 সর্বশেষ valid person

***

## 📊 Example

| name | weight | turn |
| ---- | ------ | ---- |
| A    | 200    | 1    |
| B    | 300    | 2    |
| C    | 600    | 3    |

***

#### Calculation

```
A → 200  
B → 500  
C → 1100 ❌
```

👉 Last valid = **B**
