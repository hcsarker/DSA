# 626. Exchange Seats

## Table: Seat

| Column  | Type    |
| ------- | ------- |
| id      | int     |
| student | varchar |

👉 id: 1, 2, 3, 4... (continuous)

***

## 🎯 Problem

👉 প্রতি **2 জন student swap করতে হবে**

```
1 ↔ 2  
3 ↔ 4  
5 ↔ 6 ...
```

👉 যদি last student single হয় → same থাকবে

***

## 🧠 Key Idea

👉 even/odd id check করতে হবে

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    CASE
        WHEN id % 2 = 1 AND id != (SELECT MAX(id) FROM Seat) THEN id + 1
        WHEN id % 2 = 0 THEN id - 1
        ELSE id
    END AS id,
    student
FROM Seat
ORDER BY id;
```

***

## 🔎 Explanation

### Case 1 — Odd id

```
id % 2 = 1
```

👉 odd → next seat

```
1 → 2  
3 → 4
```

***

### Case 2 — Even id

```
id % 2 = 0
```

👉 even → previous seat

```
2 → 1  
4 → 3
```

***

### Case 3 — Last odd

```
id = MAX(id)
```

👉 swap হবে না

***

## 📊 Example

| id | student |
| -- | ------- |
| 1  | A       |
| 2  | B       |
| 3  | C       |

***

#### Output

| id | student |
| -- | ------- |
| 1  | B       |
| 2  | A       |
| 3  | C       |
