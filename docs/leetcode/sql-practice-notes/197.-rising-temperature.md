# 197. Rising Temperature

## Table: Weather

| Column Name | Type |
| ----------- | ---- |
| id          | int  |
| recordDate  | date |
| temperature | int  |

* `recordDate` → unique
* প্রতিদিনের temperature দেওয়া আছে

***

## Problem

Find all **id** যেখানে:



```
আজকের temperature > গতকালের temperature
```

***

## 🧠 Key Idea

👉 আজকের row কে **গতকালের row এর সাথে compare করতে হবে**

👉 তাই ব্যবহার করবো:

```
SELF JOIN
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT w1.id
FROM Weather w1
JOIN Weather w2
ON w1.recordDate = w2.recordDate + INTERVAL '1 day'
WHERE w1.temperature > w2.temperature;
```

***

## 🔎 Explanation

### Step 1 — Self Join

```
FROM Weather w1
JOIN Weather w2
```

* `w1` → আজকের data
* `w2` → গতকালের data

***

### Step 2 — Match yesterday

```
w1.recordDate = w2.recordDate + INTERVAL '1 day'
```

মানে:

```
today = yesterday + 1 day
```

***

### Step 3 — Compare temperature

```
w1.temperature > w2.temperature
```

👉 আজ বেশি হলে select হবে

***

## 📊 Example

#### Input

| id | date       | temp |
| -- | ---------- | ---- |
| 1  | 2020-01-01 | 10   |
| 2  | 2020-01-02 | 25   |
| 3  | 2020-01-03 | 20   |

***

#### Compare

* Day2 (25 > 10) ✅
* Day3 (20 > 25) ❌

***

#### Output

| id |
| -- |

| 2 |
| - |
