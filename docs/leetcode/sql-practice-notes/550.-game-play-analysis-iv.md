# 550. Game Play Analysis IV

## Table: Activity

| Column        | Type |
| ------------- | ---- |
| player\_id    | int  |
| device\_id    | int  |
| event\_date   | date |
| games\_played | int  |

* `(player_id, event_date)` → Primary Key

***

## 🎯 Problem

Find:

```
fraction of players who logged in again
on the next day of their first login
```

Formula:

```
(players who returned next day) / (total players)
```

***

## 🧠 Key Idea

👉 First login date বের করতে হবে

👉 তারপর check:

```
first_date + 1 day = next login আছে কি না
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    ROUND(
        COUNT(DISTINCT a.player_id)::numeric 
        / (SELECT COUNT(DISTINCT player_id) FROM Activity),
    2) AS fraction
FROM Activity a
JOIN (
    SELECT player_id, MIN(event_date) AS first_date
    FROM Activity
    GROUP BY player_id
) f
ON a.player_id = f.player_id
AND a.event_date = f.first_date + INTERVAL '1 day';
```

***

## 🔎 Explanation

### Step 1 — First login

```
MIN(event_date)
```

👉 player এর first login

***

### Step 2 — Check next day login

```
event_date = first_date + 1 day
```

👉 next day login করেছে কিনা

***

### Step 3 — Count players

```
COUNT(DISTINCT player_id)
```

***

### Step 4 — Total players

```
SELECT COUNT(DISTINCT player_id)
```

***

### Step 5 — Fraction

```
returned / total
```

***

### Step 6 — Round

```
ROUND(..., 2)
```

***

## 📊 Example

| player | date |
| ------ | ---- |
| 1      | 01   |
| 1      | 02   |
| 2      | 05   |

***

#### Calculation

1 returned / 2 total = 0.50
