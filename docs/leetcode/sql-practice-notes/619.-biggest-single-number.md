# 619. Biggest Single Number

## Table: MyNumbers

| Column | Type |
| ------ | ---- |
| num    | int  |

👉 duplicate থাকতে পারে

***

## 🎯 Problem

Find:

```
largest number যা মাত্র 1 বার এসেছে
```

👉 যদি না থাকে → return `NULL`

***

## 🧠 Key Idea

👉 আগে count করতে হবে:

```
which numbers appear once
```

👉 তারপর:

```
MAX() দিয়ে largest নিতে হবে
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT MAX(num) AS num
FROM (
    SELECT num
    FROM MyNumbers
    GROUP BY num
    HAVING COUNT(num) = 1
) AS single_numbers;
```

***

## 🔎 Explanation

### Step 1 — Group by number

```
GROUP BY num
```

***

### Step 2 — Filter single সংখ্যা

```
HAVING COUNT(num) = 1
```

👉 শুধু যেগুলো 1 বার এসেছে

***

### Step 3 — Get largest

```
MAX(num)
```

***

## 📊 Example

#### Input

| num |
| --- |
| 1   |
| 2   |
| 2   |
| 3   |

***

#### Calculation

```
1 → single  
2 → duplicate  
3 → single  

largest = 3
```

***

#### Output

3
