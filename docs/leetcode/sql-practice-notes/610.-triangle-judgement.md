# 610. Triangle Judgement

## Table: Triangle

| Column | Type |
| ------ | ---- |
| x      | int  |
| y      | int  |
| z      | int  |

***

## 🎯 Problem

Check:

```
3টি side দিয়ে triangle বানানো যাবে কি না
```

***

## 🧠 Triangle Rule

👉 Triangle possible যদি:

```
x + y > z  
x + z > y  
y + z > x
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    x, y, z,
    CASE 
        WHEN x + y > z 
         AND x + z > y 
         AND y + z > x 
        THEN 'Yes'
        ELSE 'No'
    END AS triangle
FROM Triangle;
```

***

## 🔎 Explanation

### CASE WHEN

```
CASE 
    WHEN condition THEN 'Yes'
    ELSE 'No'
END
```

👉 condition true হলে → Yes\
👉 না হলে → No

***

## 📊 Example

| x | y | z |
| - | - | - |
| 3 | 4 | 5 |

```
3+4>5 ✔  
3+5>4 ✔  
4+5>3 ✔  
→ Yes
```

***

| x | y | z |
| - | - | - |
| 1 | 2 | 3 |

```
1+2=3 ❌ (not >)  
→ No
```
