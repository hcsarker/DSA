# 602. Friend Requests II: Who Has the Most Friends

## Table: RequestAccepted

| requester\_id | accepter\_id |
| ------------- | ------------ |

👉 friend relation = **both sides**

```
A → B  ⇒ A friend +1  
         B friend +1
```

***

## 🎯 Problem

```
কার সবচেয়ে বেশি friend আছে + total friend count
```

***

## 🧠 Key Idea

👉 requester + accepter → একসাথে count করতে হবে

***

## ✅ Simple SQL (PostgreSQL)

```
SELECT id, COUNT(*) AS num
FROM (
    SELECT requester_id AS id FROM RequestAccepted
    UNION ALL
    SELECT accepter_id FROM RequestAccepted
) t
GROUP BY id
ORDER BY num DESC
LIMIT 1;
```

***

## 🔎 Easy Explanation

### Step 1 — দুই পাশ একসাথে

```
requester_id  
accepter_id
```

👉 দুইজনই friend count পাবে

***

### Step 2 — combine

```
UNION ALL
```

👉 সব id একসাথে

***

### Step 3 — count

```
GROUP BY id
COUNT(*)
```

***

### Step 4 — max

```
ORDER BY num DESC
LIMIT 1
```
