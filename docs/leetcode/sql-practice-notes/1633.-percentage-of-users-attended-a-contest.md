# 1633. Percentage of Users Attended a Contest

## Tables

### Users

| Column     | Type    |
| ---------- | ------- |
| user\_id   | int     |
| user\_name | varchar |

👉 total users এখান থেকে count হবে

***

### Register

| Column      | Type |
| ----------- | ---- |
| contest\_id | int  |
| user\_id    | int  |

👉 কে কোন contest এ register করেছে

***

## 🎯 Problem

Find:

```
percentage of users per contest
```

Formula:

```
(contest users / total users) × 100
```

Return sorted:

* percentage ↓ (descending)
* contest\_id ↑ (ascending)

***

## 🧠 Key Idea

👉 total users → Users table\
👉 contest wise users → Register table

👉 তাই:

```
COUNT / total COUNT
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    r.contest_id,
    ROUND(
        COUNT(r.user_id)::numeric 
        / (SELECT COUNT(*) FROM Users) * 100,
    2) AS percentage
FROM Register r
GROUP BY r.contest_id
ORDER BY percentage DESC, r.contest_id ASC;
```

***

## 🔎 Explanation

### Step 1 — Count users per contest

```
COUNT(r.user_id)
```

***

### Step 2 — Total users

```
(SELECT COUNT(*) FROM Users)
```

***

### Step 3 — Percentage

```
(count / total) * 100
```

***

### Step 4 — Round

```
ROUND(..., 2)
```

***

### Step 5 — Sort

```
ORDER BY percentage DESC, contest_id ASC
```

***

## 📊 Example

#### Users = 4

#### Register

| contest | users   |
| ------- | ------- |
| 1       | 2 users |
| 2       | 1 user  |

***

#### Calculation

contest 1 → (2/4)\*100 = 50.00\
contest 2 → (1/4)\*100 = 25.00
