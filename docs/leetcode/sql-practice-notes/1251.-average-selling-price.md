# 1251. Average Selling Price

## Tables

### Prices

| Column      | Type |
| ----------- | ---- |
| product\_id | int  |
| start\_date | date |
| end\_date   | date |
| price       | int  |

👉 প্রতিটি product এর price একটি **date range** এর জন্য valid

***

### UnitsSold

| Column         | Type |
| -------------- | ---- |
| product\_id    | int  |
| purchase\_date | date |
| units          | int  |

👉 প্রতিটি sale record

***

## 🎯 Problem

Find:

```
average selling price per product
```

Formula:

```
(price × units) / total units
```

⚠ Special case:

```
no sales → average = 0
```

***

## 🧠 Key Idea

👉 কোন date এ sale হয়েছে → সেই date অনুযায়ী price নিতে হবে

👉 তাই join condition হবে:

```
purchase_date BETWEEN start_date AND end_date
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    p.product_id,
    ROUND(
        COALESCE(
            SUM(p.price * u.units)::numeric 
            / NULLIF(SUM(u.units), 0),
        0),
    2) AS average_price
FROM Prices p
LEFT JOIN UnitsSold u
ON p.product_id = u.product_id
AND u.purchase_date BETWEEN p.start_date AND p.end_date
GROUP BY p.product_id;
```

***

## 🔎 Explanation

### Step 1 — Join with date condition

```
u.purchase_date BETWEEN p.start_date AND p.end_date
```

👉 sale কোন price range এ পড়ছে তা match করা

***

### Step 2 — Total revenue

```
SUM(p.price * u.units)
```

👉 total টাকা

***

### Step 3 — Total units

```
SUM(u.units)
```

***

### Step 4 — Average price

```
SUM(price * units) / SUM(units)
```

***

### Step 5 — Handle zero बिक्री

```
NULLIF(SUM(u.units), 0)
COALESCE(..., 0)
```

👉 no sales → 0

***

### Step 6 — Round

```
ROUND(..., 2)
```

***

## 📊 Example

#### Prices

| product | start | end | price |
| ------- | ----- | --- | ----- |
| 1       | 01    | 10  | 5     |
| 1       | 11    | 20  | 10    |

***

#### UnitsSold

| product | date | units |
| ------- | ---- | ----- |
| 1       | 05   | 2     |
| 1       | 15   | 3     |

***

#### Calculation

```
(5×2 + 10×3) / (2+3)
= (10 + 30) / 5
= 8.00
```

***

## 📌 Concepts Used

* LEFT JOIN
* BETWEEN (date range join)
* SUM()
* GROUP BY
* NULLIF + COALESCE
* ROUND
