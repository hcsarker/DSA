# 1174. Immediate Food Delivery II

## Table: Delivery

| Column                         | Type |
| ------------------------------ | ---- |
| delivery\_id                   | int  |
| customer\_id                   | int  |
| order\_date                    | date |
| customer\_pref\_delivery\_date | date |

***

## 🎯 Problem

👉 প্রতিটি customer এর **first order** নিতে হবে

👉 তারপর check করতে হবে:

```
order_date = preferred_date → immediate
```

👉 Finally:

```
(immediate first orders / total customers) × 100
```

***

## 🧠 Key Idea

👉 First order বের করতে হবে → **MIN(order\_date)**

👉 তারপর percentage calculate

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    ROUND(
        SUM(
            CASE 
                WHEN d.order_date = d.customer_pref_delivery_date THEN 1 
                ELSE 0 
            END
        ) * 100.0 / COUNT(*),
    2) AS immediate_percentage
FROM Delivery d
JOIN (
    SELECT customer_id, MIN(order_date) AS first_date
    FROM Delivery
    GROUP BY customer_id
) f
ON d.customer_id = f.customer_id
AND d.order_date = f.first_date;
```

***

## 🔎 Explanation

### Step 1 — First order per customer

```
SELECT customer_id, MIN(order_date)
```

👉 earliest order

***

### Step 2 — Join with original table

👉 full row পেতে

***

### Step 3 — Check immediate

```
order_date = customer_pref_delivery_date
```

👉 immediate → 1\
👉 না হলে → 0

***

### Step 4 — Percentage

```
SUM(...) * 100 / COUNT(*)
```

***

### Step 5 — Round

```
ROUND(..., 2)
```

***

#### Calculation

1 immediate / 2 total = 50.00%
