# 176. Second Highest Salary

## Table: Employee

| Column | Type |
| ------ | ---- |
| id     | int  |
| salary | int  |

***

## 🎯 Problem

Find:

```
2nd highest distinct salary
```

If no second highest salary exists:

```
return NULL
```

***

## 🧠 Key Idea

👉 First highest salary বাদ দিতে হবে

👉 তারপর highest salary নিতে হবে

***

## ✅ PostgreSQL Solution

```
SELECT (    SELECT DISTINCT salary    FROM Employee    ORDER BY salary DESC    OFFSET 1    LIMIT 1) AS SecondHighestSalary;
```

***

## 🔎 Explanation

#### Sort salary descending

```
ORDER BY salary DESC
```

Example:

| salary |
| ------ |
| 300    |
| 200    |
| 100    |

***

#### Skip first row

```
OFFSET 1
```

👉 300 skip

***

#### Take next row

```
LIMIT 1
```

👉 200

***

## 📊 Example

#### Employee

| id | salary |
| -- | ------ |
| 1  | 100    |
| 2  | 200    |
| 3  | 300    |
