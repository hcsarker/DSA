# 1978. Employees Whose Manager Left the Company

## Table: Employees

| Column       | Type    |
| ------------ | ------- |
| employee\_id | int     |
| name         | varchar |
| manager\_id  | int     |
| salary       | int     |

***

## 🎯 Problem

Find employees:

```
- salary < 30000
- manager_id আছে কিন্তু manager table এ নেই
```

👉 মানে manager company ছেড়ে গেছে

***

## 🧠 Key Idea

👉 check করতে হবে:

```
manager_id NOT IN employee_id
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT employee_id
FROM Employees
WHERE salary < 30000
AND manager_id IS NOT NULL
AND manager_id NOT IN (
    SELECT employee_id FROM Employees
)
ORDER BY employee_id;
```

***

## 🔎 Explanation

### Step 1 — Salary condition

```
salary < 30000
```

***

### Step 2 — Has manager

```
manager_id IS NOT NULL
```

***

### Step 3 — Manager not exists

```
manager_id NOT IN (SELECT employee_id FROM Employees)
```

👉 manager table এ নাই → left company

***

### Step 4 — Sort

```
ORDER BY employee_id
```

***

## 📊 Example

| emp | manager | salary |
| --- | ------- | ------ |
| 1   | 10      | 20000  |
| 2   | NULL    | 50000  |

👉 manager 10 table এ নাই

***

#### Output

```
1
```
