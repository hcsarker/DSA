# 1068. Product Sales Analysis I

## Tables

### Sales

| Column Name | Type |
| ----------- | ---- |
| sale\_id    | int  |
| product\_id | int  |
| year        | int  |
| quantity    | int  |
| price       | int  |

* `(sale_id, year)` → Primary Key
* `product_id` → Foreign Key → Product table

***

### Product

| Column Name   | Type    |
| ------------- | ------- |
| product\_id   | int     |
| product\_name | varchar |

* `product_id` → Primary Key

***

## Problem

Report the following information for each sale:

* `product_name`
* `year`
* `price`

***

## Key Idea

`product_name` **Product table** এ আছে\
`year` এবং `price` **Sales table** এ আছে

তাই আমাদের **JOIN** করতে হবে।

***

## SQL Solution (PostgreSQL)

```
SELECT p.product_name, s.year, s.price
FROM Sales s
JOIN Product p
ON s.product_id = p.product_id;
```

***

## Explanation

### Step 1 — Join the tables

```
JOIN Product p
ON s.product_id = p.product_id
```

এটা **Sales** এবং **Product** টেবিলকে connect করে।

***

### Step 2 — Select required columns

```
SELECT p.product_name, s.year, s.price
```

আমরা শুধু এই 3টা column চাই।

***

## Example

#### Sales

| sale\_id | product\_id | year | price |
| -------- | ----------- | ---- | ----- |
| 1        | 100         | 2008 | 500   |
| 2        | 200         | 2011 | 900   |

***

#### Product

| product\_id | product\_name |
| ----------- | ------------- |
| 100         | Nokia         |
| 200         | Apple         |

***

#### Output

| product\_name | year | price |
| ------------- | ---- | ----- |
| Nokia         | 2008 | 500   |
| Apple         | 2011 | 900   |
