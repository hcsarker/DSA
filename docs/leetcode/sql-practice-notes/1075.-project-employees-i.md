# 1075. Project Employees I

## Tables

### Project

| Column       | Type |
| ------------ | ---- |
| project\_id  | int  |
| employee\_id | int  |

* `(project_id, employee_id)` → Primary Key
* কোন employee কোন project এ কাজ করছে

***

### Employee

| Column            | Type    |
| ----------------- | ------- |
| employee\_id      | int     |
| name              | varchar |
| experience\_years | int     |

* `employee_id` → Primary Key
* `experience_years` → experience

***

## 🎯 Problem

Find:

```
average experience years per project
```

Return:

\| project\_id | average\_years |

* Rounded to **2 decimal places**

***

## 🧠 Key Idea

👉 Project table → employee list\
👉 Employee table → experience

👉 তাই:

```
JOIN + AVG()
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    p.project_id,
    ROUND(AVG(e.experience_years), 2) AS average_years
FROM Project p
JOIN Employee e
ON p.employee_id = e.employee_id
GROUP BY p.project_id;
```

***

## 🔎 Explanation

### Step 1 — JOIN tables

```
ON p.employee_id = e.employee_id
```

👉 project + employee connect

***

### Step 2 — Get average

```
AVG(e.experience_years)
```

👉 প্রতি project এর average experience

***

### Step 3 — Group by project

```
GROUP BY p.project_id
```

***

### Step 4 — Round result

```
ROUND(..., 2)
```

***

## 📊 Example

#### Project

| project | employee |
| ------- | -------- |
| 1       | 1        |
| 1       | 2        |

***

#### Employee

| employee | experience |
| -------- | ---------- |
| 1        | 3          |
| 2        | 5          |

***

#### Calculation

```
(3 + 5) / 2 = 4.00
```

***

#### Output

| project\_id | average\_years |
| ----------- | -------------- |
| 1           | 4.00           |
