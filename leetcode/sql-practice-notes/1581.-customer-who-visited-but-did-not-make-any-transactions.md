# 1581. Customer Who Visited but Did Not Make Any Transactions

## Tables

### Visits

| Column Name  | Type |
| ------------ | ---- |
| visit\_id    | int  |
| customer\_id | int  |

* `visit_id` → unique

***

### Transactions

| Column Name     | Type |
| --------------- | ---- |
| transaction\_id | int  |
| visit\_id       | int  |
| amount          | int  |

* `visit_id` → FK (Visits)

***

## Problem

Find:

* Customers who **visited but did NOT make any transaction**
* Count how many times they did such visits

Return:

\| customer\_id | count\_no\_trans |

***

## 🧠 Key Idea

👉 এমন visit খুঁজতে হবে যেগুলোর\
**Transactions table এ match নাই**

👉 মানে:

```
LEFT JOIN + NULL check
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT v.customer_id, COUNT(*) AS count_no_trans
FROM Visits v
LEFT JOIN Transactions t
ON v.visit_id = t.visit_id
WHERE t.visit_id IS NULL
GROUP BY v.customer_id;
```

***

## 🔎 Explanation

### Step 1 — LEFT JOIN

```
LEFT JOIN Transactions t
ON v.visit_id = t.visit_id
```

* সব Visits থাকবে
* Transaction থাকলে join হবে
* না থাকলে → NULL

***

### Step 2 — Find visits with NO transaction

```
WHERE t.visit_id IS NULL
```

👉 মানে এই visit এ কোনো transaction হয়নি

***

### Step 3 — Count per customer

```
GROUP BY v.customer_id
```

```
COUNT(*)
```

👉 কতবার এমন visit করেছে

***

## 📊 Example

#### Visits

| visit\_id | customer\_id |
| --------- | ------------ |
| 1         | 23           |
| 2         | 9            |
| 3         | 23           |

***

#### Transactions

| transaction\_id | visit\_id |
| --------------- | --------- |
| 1               | 2         |

***

#### Valid visits (no transaction)

| visit\_id | customer\_id |
| --------- | ------------ |
| 1         | 23           |
| 3         | 23           |

***

#### Output

| customer\_id | count\_no\_trans |
| ------------ | ---------------- |
| 23           | 2                |
