# 570. Managers with at Least 5 Direct Reports

## Table: Employee

| Column     | Type    |
| ---------- | ------- |
| id         | int     |
| name       | varchar |
| department | varchar |
| managerId  | int     |

* `id` → employee id
* `managerId` → manager এর id

***

## 🎯 Problem

Find managers who have:

```
at least 5 direct reports
```

Return:

\| name |

***

## 🧠 Key Idea

👉 manager কে identify করতে হবে employee table থেকেই

👉 logic:

```
same managerId → same manager
COUNT ≥ 5
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT e.name
FROM Employee e
JOIN (
    SELECT managerId
    FROM Employee
    GROUP BY managerId
    HAVING COUNT(*) >= 5
) m
ON e.id = m.managerId;
```

***

## 🔎 Explanation

### Step 1 — Count employees per manager

```
SELECT managerId
FROM Employee
GROUP BY managerId
HAVING COUNT(*) >= 5
```

👉 যেসব manager এর under এ ≥ 5 employee আছে

***

### Step 2 — Join to get manager name

```
ON e.id = m.managerId
```

👉 managerId = employee id → manager কে match করা

***

#### Employee

## 🚀 Alternative (Short Solution)

```
SELECT name
FROM Employee
WHERE id IN (
    SELECT managerId
    FROM Employee
    GROUP BY managerId
    HAVING COUNT(*) >= 5
);
```
