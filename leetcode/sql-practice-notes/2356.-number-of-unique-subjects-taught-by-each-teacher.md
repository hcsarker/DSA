# 2356. Number of Unique Subjects Taught by Each Teacher

## Table: Teacher

| Column      | Type |
| ----------- | ---- |
| teacher\_id | int  |
| subject\_id | int  |
| dept\_id    | int  |

👉 একই subject বিভিন্ন dept এ থাকতে পারে

***

## 🎯 Problem

Find:

```
number of UNIQUE subjects per teacher
```

Return:

\| teacher\_id | cnt |

***

## 🧠 Key Idea

👉 duplicate subject থাকতে পারে (different dept এ)

👉 তাই ব্যবহার করবো:

```
COUNT(DISTINCT subject_id)
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    teacher_id,
    COUNT(DISTINCT subject_id) AS cnt
FROM Teacher
GROUP BY teacher_id;
```

***

## 🔎 Explanation

### Step 1 — Group by teacher

```
GROUP BY teacher_id
```

👉 প্রতি teacher আলাদা

***

### Step 2 — Count unique subjects

```
COUNT(DISTINCT subject_id)
```

👉 same subject multiple dept এ থাকলেও 1 বার count হবে

***

## 📊 Example

#### Input

| teacher | subject | dept |
| ------- | ------- | ---- |
| 1       | 101     | 1    |
| 1       | 101     | 2    |
| 1       | 102     | 1    |

***

#### Calculation

teacher 1 → subjects: 101, 102\
count = 2
