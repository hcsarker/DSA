# 577. Employee Bonus

## Tables

### Employee

| Column     | Type    |
| ---------- | ------- |
| empId      | int     |
| name       | varchar |
| supervisor | int     |
| salary     | int     |

***

### Bonus

| Column | Type |
| ------ | ---- |
| empId  | int  |
| bonus  | int  |

***

## 🎯 Problem

Find:

* Employees whose **bonus < 1000**\
  **OR**
* Employees who **do not have any bonus**

Return:

\| name | bonus |

***

## 🧠 Key Idea

👉 কিছু employee এর bonus নাই → NULL হবে\
👉 তাই ব্যবহার করবো:

```
LEFT JOIN + NULL check
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT e.name, b.bonus
FROM Employee e
LEFT JOIN Bonus b
ON e.empId = b.empId
WHERE b.bonus < 1000
OR b.bonus IS NULL;
```

***

## 🔎 Explanation

### Step 1 — LEFT JOIN

```
LEFT JOIN Bonus b
ON e.empId = b.empId
```

👉 সব employee থাকবে\
👉 bonus না থাকলে → NULL

***

### Step 2 — Apply condition

```
b.bonus < 1000
OR b.bonus IS NULL
```

👉 দুইটা case:

* bonus আছে কিন্তু < 1000
* bonus নাই

***

## 📊 Example

#### Employee

| empId | name |
| ----- | ---- |
| 1     | John |
| 2     | Dan  |
| 3     | Brad |

***

#### Bonus

| empId | bonus |
| ----- | ----- |
| 1     | 500   |
| 2     | 2000  |

***

#### Output

| name | bonus |
| ---- | ----- |
| John | 500   |
| Brad | NULL  |
