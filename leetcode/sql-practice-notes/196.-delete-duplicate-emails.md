# 196. Delete Duplicate Emails

## Table: Person

| Column | Type    |
| ------ | ------- |
| id     | int     |
| email  | varchar |

👉 `id` = Primary Key

***

## 🎯 Problem

Duplicate emails delete করতে হবে।

```
একই email থাকলেসবচেয়ে ছোট id রাখবেবাকিগুলো delete করবে
```

***

## 🧠 Key Idea

👉 প্রতিটি email এর জন্য:

```
MIN(id) → keepother ids → delete
```

***

## ✅ PostgreSQL Solution

```
DELETE FROM PersonWHERE id NOT IN (    SELECT MIN(id)    FROM Person    GROUP BY email);
```

***

## 🔎 Explanation

#### Step 1

```
SELECT MIN(id)FROM PersonGROUP BY email;
```

Example:

| email       | MIN(id) |
| ----------- | ------- |
| a@gmail.com |         |

| 1 |
| - |

| b@gmail.com |
| ----------- |

| 2 |
| - |

👉 যেগুলো রাখতে হবে

***

#### Step 2

```
DELETE FROM PersonWHERE id NOT IN (...)
```

👉 smallest id ছাড়া বাকি duplicate rows delete
