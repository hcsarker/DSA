# 185. Department Top Three Salaries

### 🎯 Problem

```
প্রতি department এর top 3 salary (unique) যাদের আছে → তাদের name দেখাও
```

***

## 🧠 Key Idea (IMPORTANT)

👉 use:

```
DENSE_RANK()
```

👉 কারণ:

```
same salary → same rank  no gap (1,2,3)
```

***

## ✅ Simple SQL (PostgreSQL)

```
SELECT 
    d.name AS Department,
    e.name AS Employee,
    e.salary
FROM (
    SELECT *,
           DENSE_RANK() OVER (
               PARTITION BY departmentId 
               ORDER BY salary DESC
           ) AS rnk
    FROM Employee
) e
JOIN Department d
ON e.departmentId = d.id
WHERE rnk <= 3;
```

***

## 🔎 Easy Explanation

### Step 1 — Rank per department

```
DENSE_RANK() OVER (PARTITION BY departmentId ORDER BY salary DESC)
```

👉 example:

| salary | rank |
| ------ | ---- |
| 100    | 1    |
| 90     | 2    |
| 90     | 2    |
| 80     | 3    |

***

### Step 2 — top 3

```
WHERE rnk <= 3
```

***

### Step 3 — department name

```
JOIN Department
```
