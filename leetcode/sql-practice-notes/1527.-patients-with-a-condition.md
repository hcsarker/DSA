# 1527. Patients With a Condition

## Table: Patients

| Column        | Type    |
| ------------- | ------- |
| patient\_id   | int     |
| patient\_name | varchar |
| conditions    | varchar |

👉 `conditions` = space separated disease codes

***

## 🎯 Problem

Find patients who have:

```
Type I Diabetes → starts with DIAB1
```

***

## 🧠 Key Idea

👉 conditions string এর ভিতরে `DIAB1` আছে কিনা check করতে হবে

```
space separated values → string search
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT patient_id, patient_name, conditionsFROM PatientsWHERE conditions LIKE 'DIAB1%'   OR conditions LIKE '% DIAB1%';
```

***

## 🔎 Explanation

### Case 1 — start of string

```
DIAB1XXX ...
```

***

### Case 2 — middle of string

```
... DIAB1XXX ...
```

***

## ⚡ Better (Clean Solution)

```
SELECT patient_id, patient_name, conditionsFROM PatientsWHERE conditions ~ '(^| )DIAB1';
```

***

## 📌 Concepts Used

* LIKE operator
* Pattern matching
* Regex (advanced)
