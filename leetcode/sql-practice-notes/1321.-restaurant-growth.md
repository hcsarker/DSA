# 1321. Restaurant Growth

## Table: Customer

| Column       | Type    |
| ------------ | ------- |
| customer\_id | int     |
| name         | varchar |
| visited\_on  | date    |
| amount       | int     |

***

## 🎯 Problem

👉 প্রতি দিনের জন্য:

```
last 7 days (current + previous 6 days)
total amount + average amount
```

***

## 🧠 Key Idea

👉 first: same date এর amount যোগ করতে হবে\
👉 then: 7 days moving window

## ✅ Simple Code (PostgreSQL)

```
WITH daily AS (
    SELECT visited_on, SUM(amount) AS amount
    FROM Customer
    GROUP BY visited_on
)

SELECT 
    visited_on,
    SUM(amount) OVER (ORDER BY visited_on ROWS 6 PRECEDING) AS amount,
    ROUND(AVG(amount) OVER (ORDER BY visited_on ROWS 6 PRECEDING), 2) AS average_amount
FROM daily
ORDER BY visited_on
OFFSET 6;
```

***

## 🧠 Super Easy Explanation

👉 Step 1

```
same date er sob amount add kori
```

👉 Step 2

```
last 7 din er sum + avg kori
```

👉 Step 3

```
first 6 din bad (OFFSET 6)
```

***

## 🔥 Shortcut Trick

ROWS 6 PRECEDING = last 7 days\
OFFSET 6 = first 6 skip
