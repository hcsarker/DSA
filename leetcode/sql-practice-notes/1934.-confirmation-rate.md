# 1934. Confirmation Rate

## Tables

### Signups

| Column      | Type     |
| ----------- | -------- |
| user\_id    | int      |
| time\_stamp | datetime |

* সব users এখানে আছে

***

### Confirmations

| Column      | Type                        |
| ----------- | --------------------------- |
| user\_id    | int                         |
| time\_stamp | datetime                    |
| action      | enum('confirmed','timeout') |

***

## 🎯 Problem

For each user:

```
confirmation rate =
confirmed count / total requests
```

⚠ Special case:

```
no confirmation request → rate = 0
```

Return:

\| user\_id | confirmation\_rate |

Rounded to **2 decimal places**

***

## 🧠 Key Idea

👉 সব user দেখাতে হবে → `Signups` base table\
👉 confirmation থাকতে পারে বা নাও থাকতে পারে → `LEFT JOIN`

👉 তারপর:

```
COUNT confirmed / COUNT total
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    s.user_id,
    ROUND(
        COALESCE(
            COUNT(CASE WHEN c.action = 'confirmed' THEN 1 END)::numeric 
            / NULLIF(COUNT(c.action),0),
        0),
    2) AS confirmation_rate
FROM Signups s
LEFT JOIN Confirmations c
ON s.user_id = c.user_id
GROUP BY s.user_id;
```

***

## 🔎 Explanation

### Step 1 — LEFT JOIN

```
LEFT JOIN Confirmations c
ON s.user_id = c.user_id
```

👉 সব user থাকবে\
👉 confirmation না থাকলে → NULL

***

### Step 2 — Count confirmed

```
COUNT(CASE WHEN c.action = 'confirmed' THEN 1 END)
```

👉 কতবার confirmed হয়েছে

***

### Step 3 — Count total requests

```
COUNT(c.action)
```

👉 মোট request

***

### Step 4 — Divide

```
confirmed / total
```

***

### Step 5 — Handle NULL case

```
COALESCE(..., 0)
```

👉 কোনো request না থাকলে → 0

***

### Step 6 — Round

```
ROUND(..., 2)
```

***

## 📊 Example

#### Confirmations

| user | action    |
| ---- | --------- |
| 1    | confirmed |
| 1    | timeout   |
| 1    | confirmed |

***

#### Calculation

confirmed = 2\
total = 3\
rate = 2/3 = 0.67
