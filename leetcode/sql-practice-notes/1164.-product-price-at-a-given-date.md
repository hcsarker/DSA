# 1164. Product Price at a Given Date

## Table: Products

| Column       | Type |
| ------------ | ---- |
| product\_id  | int  |
| new\_price   | int  |
| change\_date | date |

👉 initially সব product এর price = **10**

***

## 🎯 Problem

Find:

```
price of each product on 2019-08-16
```

***

## 🧠 Key Idea

👉 ওই date পর্যন্ত **last updated price** নিতে হবে

👉 যদি কোনো update না থাকে → default = 10

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    p.product_id,
    COALESCE(MAX(pr.new_price), 10) AS price
FROM (
    SELECT DISTINCT product_id
    FROM Products
) p
LEFT JOIN Products pr
ON p.product_id = pr.product_id
AND pr.change_date <= '2019-08-16'
GROUP BY p.product_id;
```

***

## 🔎 Explanation

### Step 1 — All products

```
SELECT DISTINCT product_id
```

👉 সব product list

***

### Step 2 — Filter date

```
change_date <= '2019-08-16'
```

👉 ওই date পর্যন্ত changes

***

### Step 3 — Latest price

```
MAX(new_price)
```

👉 latest change (last price)

***

### Step 4 — Default value

```
COALESCE(..., 10)
```

👉 change না থাকলে → 10

***

## 📊 Example

| product | price | date       |
| ------- | ----- | ---------- |
| 1       | 20    | 2019-08-10 |
| 1       | 30    | 2019-08-20 |

***

#### Calculation

2019-08-16 এর আগে last = 20
