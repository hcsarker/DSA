# 1729. Find Followers Count

## Table: Followers

| Column       | Type |
| ------------ | ---- |
| user\_id     | int  |
| follower\_id | int  |

👉 `follower_id` → কে follow করছে\
👉 `user_id` → কাকে follow করছে

***

## 🎯 Problem

Find:

```
number of followers per user
```

Return sorted by:

```
user_id ASC
```

***

## 🧠 Key Idea

👉 follower count =

```
COUNT(follower_id)
```

👉 group by user

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    user_id,
    COUNT(follower_id) AS followers_count
FROM Followers
GROUP BY user_id
ORDER BY user_id;
```

***

## 🔎 Explanation

### Step 1 — Group by user

```
GROUP BY user_id
```

👉 প্রতি user আলাদা

***

### Step 2 — Count followers

```
COUNT(follower_id)
```

👉 কয়জন follow করছে

***

### Step 3 — Sort

```
ORDER BY user_id
```

***

## 📊 Example

#### Input

| user | follower |
| ---- | -------- |
| 1    | 2        |
| 1    | 3        |
| 2    | 1        |

***

#### Calculation

```
user 1 → 2 followers  
user 2 → 1 follower  
```

***

#### Output

| user\_id | followers\_count |
| -------- | ---------------- |
| 1        | 2                |
| 2        | 1                |
