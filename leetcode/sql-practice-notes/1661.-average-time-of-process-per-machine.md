# 1661. Average Time of Process per Machine

## Table: Activity

| Column         | Type                |
| -------------- | ------------------- |
| machine\_id    | int                 |
| process\_id    | int                 |
| activity\_type | enum('start','end') |
| timestamp      | float               |

* প্রতিটি `(machine_id, process_id)` এর জন্য:
  * 1টা `start`
  * 1টা `end`

***

## 🎯 Problem

Find:

```
average processing time per machine
```

Where:

```
processing time = end - start
```

Final output:

\| machine\_id | processing\_time |

* Rounded to **3 decimal places**

***

## 🧠 Key Idea

👉 একই process এর `start` আর `end` কে একসাথে আনতে হবে

👉 তারপর:

```
(end - start) → per process
AVG() → per machine
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    machine_id,
    ROUND(AVG(end_time - start_time)::numeric, 3) AS processing_time
FROM (
    SELECT 
        machine_id,
        process_id,
        MAX(CASE WHEN activity_type = 'end' THEN timestamp END) AS end_time,
        MIN(CASE WHEN activity_type = 'start' THEN timestamp END) AS start_time
    FROM Activity
    GROUP BY machine_id, process_id
) t
GROUP BY machine_id;
```

***

## 🔎 Explanation

### Step 1 — Get start & end time per process

```
GROUP BY machine_id, process_id
```

```
MAX(CASE WHEN activity_type = 'end' THEN timestamp END)
MIN(CASE WHEN activity_type = 'start' THEN timestamp END)
```

👉 এতে আমরা পাই:

| machine | process | start | end |
| ------- | ------- | ----- | --- |
| 1       | 1       | 1.0   | 3.0 |
| 1       | 2       | 2.0   | 5.0 |

***

### Step 2 — Calculate processing time

```
end_time - start_time
```

***

### Step 3 — Average per machine

```
AVG(end_time - start_time)
```

***

### Step 4 — Round result

```
ROUND(..., 3)
```

***

## 📊 Example

#### Input

| machine | process | type  | time |
| ------- | ------- | ----- | ---- |
| 1       | 1       | start | 1    |
| 1       | 1       | end   | 3    |
| 1       | 2       | start | 2    |
| 1       | 2       | end   | 5    |

***

#### Processing time

* Process 1 → 3 - 1 = 2
* Process 2 → 5 - 2 = 3

Average:

```
(2 + 3) / 2 = 2.5
```

***

#### Output

| machine\_id | processing\_time |
| ----------- | ---------------- |
| 1           | 2.500            |
