# 1907. Count Salary Categories

## Table: Accounts

| Column      | Type |
| ----------- | ---- |
| account\_id | int  |
| income      | int  |

***

## 🎯 Problem

Divide accounts into 3 categories:

```
Low Salary     → income < 20000  
Average Salary → 20000 ≤ income ≤ 50000  
High Salary    → income > 50000  
```

👉 প্রতিটা category তে কয়টা account আছে count করতে হবে

👉 সব category return করতে হবে (even 0 হলে)

***

## 🧠 Key Idea

👉 `CASE WHEN` দিয়ে category বানাতে পারি\
👉 কিন্তু missing category handle করতে হবে

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    'Low Salary' AS category,
    COUNT(*) FILTER (WHERE income < 20000) AS accounts_count
FROM Accounts

UNION

SELECT 
    'Average Salary',
    COUNT(*) FILTER (WHERE income BETWEEN 20000 AND 50000)
FROM Accounts

UNION

SELECT 
    'High Salary',
    COUNT(*) FILTER (WHERE income > 50000)
FROM Accounts;
```

***

## 🔎 Explanation

### Low Salary

```
income < 20000
```

***

### Average Salary

```
income BETWEEN 20000 AND 50000
```

***

### High Salary

```
income > 50000
```

***

### UNION

👉 3টা row combine করা

***

## 📊 Example

| income |
| ------ |
| 10000  |
| 30000  |
| 60000  |

***

#### Output

| category       | count |
| -------------- | ----- |
| Low Salary     | 1     |
| Average Salary | 1     |
| High Salary    | 1     |
