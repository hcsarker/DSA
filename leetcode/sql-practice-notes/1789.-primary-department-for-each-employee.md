# 1789. Primary Department for Each Employee

## Table: Employee

| Column         | Type    |
| -------------- | ------- |
| employee\_id   | int     |
| department\_id | int     |
| primary\_flag  | varchar |

👉 `primary_flag = 'Y'` → primary department

***

## 🎯 Problem

Find:

```
each employee এর primary department
```

#### Rules:

1️⃣ যদি multiple department থাকে → `'Y'` যেটা সেটাই primary\
2️⃣ যদি only 1 department থাকে → সেটাই primary (even if 'N')

***

## 🧠 Key Idea

👉 2টা case handle করতে হবে:

```
- primary_flag = 'Y'
- OR only one department
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT employee_id, department_id
FROM Employee
WHERE primary_flag = 'Y'

UNION

SELECT employee_id, department_id
FROM Employee
GROUP BY employee_id
HAVING COUNT(*) = 1;
```

***

## 🔎 Explanation

### Case 1 — Primary flag

```
WHERE primary_flag = 'Y'
```

👉 direct primary

***

### Case 2 — Only one department

```
GROUP BY employee_id
HAVING COUNT(*) = 1
```

👉 only 1 dept → সেটাই primary

***

### UNION

👉 দুই result combine করা

***

## 📊 Example

| emp | dept | flag |
| --- | ---- | ---- |
| 1   | 10   | N    |
| 2   | 20   | Y    |
| 2   | 30   | N    |

***

#### Output

| emp | dept |
| --- | ---- |
| 1   | 10   |
| 2   | 20   |
