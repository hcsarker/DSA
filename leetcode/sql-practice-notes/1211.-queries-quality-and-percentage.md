# 1211. Queries Quality and Percentage

## Table: Queries

| Column      | Type    |
| ----------- | ------- |
| query\_name | varchar |
| result      | varchar |
| position    | int     |
| rating      | int     |

* `rating < 3` → **poor query**

***

## 🎯 Problem

For each `query_name`, find:

#### 1️⃣ Quality

```
AVG(rating / position)
```

#### 2️⃣ Poor Query Percentage

```
(count of rating < 3 / total count) × 100
```

👉 Round both to **2 decimal places**

***

## 🧠 Key Idea

👉 group by `query_name`

👉 use:

```
AVG()
COUNT()
CASE WHEN
```

***

## ✅ SQL Solution (PostgreSQL)

```
SELECT 
    query_name,
    ROUND(AVG(rating::numeric / position), 2) AS quality,
    ROUND(
        COUNT(*) FILTER (WHERE rating < 3) * 100.0 / COUNT(*),
    2) AS poor_query_percentage
FROM Queries
GROUP BY query_name;
```

***

## 🔎 Explanation

### Step 1 — Quality

```
AVG(rating / position)
```

👉 প্রতিটা row এর (rating ÷ position) average

***

### Step 2 — Poor query count

```
COUNT(*) FILTER (WHERE rating < 3)
```

👉 কয়টা poor query

***

### Step 3 — Total count

```
COUNT(*)
```

***

### Step 4 — Percentage

```
(poor / total) * 100
```

***

### Step 5 — Round

```
ROUND(..., 2)
```

***

## 📊 Example

#### Input

| query | rating | position |
| ----- | ------ | -------- |
| dog   | 5      | 1        |
| dog   | 2      | 2        |
| dog   | 3      | 3        |

***

#### Calculation

**Quality:**

```
(5/1 + 2/2 + 3/3) / 3
= (5 + 1 + 1) / 3
= 2.33
```

**Poor %:**

1 poor (rating < 3) out of 3\
\= 33.33%
